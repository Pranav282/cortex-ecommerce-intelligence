# CortexCommerce

CortexCommerce is an AI-powered eCommerce customer lifecycle and
decision-intelligence platform built using Snowflake, dbt, Snowpark,
Snowflake Cortex, and Streamlit.

## Project objectives

- Build a tested eCommerce analytical warehouse
- Analyze customer lifecycle and conversion behavior
- Develop purchase-propensity and customer-risk models
- Detect anomalies in business performance
- Enable natural-language analysis with Snowflake Cortex
- Generate validated, evidence-backed business recommendations

## Data

The project uses the public TheLook eCommerce dataset, containing
users, orders, products, inventory, distribution centers, and
website-event data.

## Technology stack

- Snowflake
- dbt
- Python and Snowpark
- Snowflake Cortex
- Streamlit
- GitHub
